# Simple Webpage

A clean and modern webpage with responsive styling and Open-Meteo weather tools.

## Features

- Responsive navigation header
- Three main sections (Home, About, Contact)
- Fixed footer
- Modern styling with hover effects
- Clean typography and layout
- Current weather, 7-day forecast, hourly temperatures, and air quality
- Random dog photo loaded from the Dog CEO API

## Files

- `index.html` - Main HTML structure
- `styles.css` - Stylesheet with all the styling
- `weather.js` - Weather data retrieval from the Open-Meteo APIs
- `weather.js` also loads random dog photos from Dog CEO

## How to Use

1. Open `index.html` in your web browser
2. Navigate between sections using the header links
3. Enter a city in a weather tool and select its button to load data
4. Select "Show a random dog" in the bonus section to load a photo

## Technologies

- HTML5, CSS3, and JavaScript
- Open-Meteo Geocoding, Forecast, and Air Quality APIs
- Dog CEO API (no authorization, HTTPS, CORS enabled)
