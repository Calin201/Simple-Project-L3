# My Simple Webpage

## Descrierea proiectului

My Simple Webpage este un proiect web simplu, realizat folosind HTML și CSS. Pagina prezintă o structură organizată, cu un antet, un meniu de navigare, mai multe secțiuni de conținut și un subsol.

Proiectul include și o secțiune Galerie, care afișează trei imagini placeholder într-o grilă adaptabilă la dimensiunea ecranului.

## Tehnologii folosite

- **HTML5** – pentru structura și organizarea conținutului paginii.
- **CSS3** – pentru stilizarea elementelor, culori, spațiere, efecte vizuale și design responsive.
- **CSS Grid** – pentru organizarea imaginilor din galerie.
- **CSS Flexbox** – pentru alinierea elementelor din meniul de navigare.

## Structura fișierelor

```text
proiect/
│
├── index.html
├── styles.css
└── README.md
```

- `index.html` – conține structura HTML a paginii.
- `styles.css` – conține regulile CSS pentru aspectul vizual.
- `README.md` – conține documentația proiectului.

## Funcționalitățile paginii

Pagina include următoarele elemente:

1. **Header** – afișează titlul paginii.
2. **Meniu de navigare** – permite accesul la secțiunile Home, About și Contact.
3. **Secțiunea Home** – prezintă o scurtă introducere.
4. **Secțiunea About** – conține informații despre proiect.
5. **Secțiunea Contact** – oferă o secțiune dedicată contactului.
6. **Secțiunea Galerie** – afișează trei imagini placeholder folosind CSS Grid.
7. **Footer** – afișează informațiile privind drepturile de autor.

### Design și stilizare

- Design simplu și modern.
- Culori și fonturi personalizate.
- Efecte vizuale la trecerea cursorului peste linkuri.
- Secțiuni cu margini rotunjite și umbre.
- Galerie cu trei coloane pe ecrane mari.
- Galerie cu o singură coloană pe ecrane mai mici de 600px.
- Elemente responsive pentru dispozitive mobile.

## Cum se deschide proiectul

Pentru a vizualiza proiectul, urmează pașii:

1. Descarcă sau copiază fișierele proiectului într-un folder de pe calculator.
2. Asigură-te că fișierele `index.html` și `styles.css` se află în același folder.
3. Deschide fișierul `index.html` folosind un browser web (Google Chrome, Mozilla Firefox, Microsoft Edge etc.).
4. Pagina web va fi afișată automat în browser.

**Important:** Nu este necesară instalarea unor programe suplimentare sau utilizarea unui server web pentru vizualizarea paginii.
