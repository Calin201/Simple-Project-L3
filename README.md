# Simple Webpage

A clean and modern HTML/CSS webpage with a responsive design.

## Features

- Responsive navigation header
- Main sections (Despre Mine, Galerie, Home, About, Contact)
- Responsive image gallery built with CSS Grid (3 columns on desktop, 1 column on screens smaller than 600px)
- Fixed footer
- Modern styling with hover effects
- Clean typography and layout

## Files

- `index.html` - Main HTML structure including the `#despre` and `#galerie` sections
- `styles.css` - Stylesheet with CSS Grid layout, media queries, and page styling

## How to Use

1. Open `index.html` in your web browser
2. Navigate between sections using the header links

## Technologies

- HTML5
- CSS3 (CSS Grid & Media Queries)
